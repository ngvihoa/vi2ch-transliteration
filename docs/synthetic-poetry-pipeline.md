# Synthetic poetry pipeline

## 1. Normalize source poems

```bash
python scripts/prepare_poem_dataset.py
```

Outputs `poem_lines.jsonl`, `poem_review.jsonl`, and `poem_report.json` under
`dataset/` without modifying the raw poems.

## 2. Generate Vietnamese IPA

vPhon is kept as a separate GPL-licensed command-line dependency:

```bash
git clone https://github.com/kirbyj/vPhon.git tools/vPhon
git -C tools/vPhon checkout 076a5d3611d688325a71ad6dbbcd5868399bf5e7
python scripts/phonemize_poems.py
```

This writes `poem_ipa.jsonl` and `poem_ipa_report.json`. Historical/OCR
spellings are mapped through `scripts/ipa_overrides.json`; source spellings and
phonemization forms are both retained.

## 3. Rank Pinyin candidates

Install pinned dependencies locally:

```bash
python -m pip install --target tools/pinyin-python -r requirements-pinyin.txt
python scripts/map_ipa_to_pinyin.py
```

The matcher compares onset, rhyme, and Chao tone contour with respective
weights 0.35, 0.45, and 0.20. The Mandarin inventory is derived from attested
Hanzi readings in `pypinyin`; neutral-tone readings are excluded. Pinyin IPA
variants are generated by `pinyin-to-ipa`.

Outputs:

- `dataset/pinyin_candidates.jsonl`: deduplicated top-k candidate sets with
  component distances, IPA, tone, Hanzi count, and example characters;
- `dataset/poem_pinyin.jsonl`: line/syllable references to candidate sets;
- `dataset/pinyin_report.json`: inventory, score distribution, weights, and
  locked dependency metadata.

The default is twenty candidates so that the downstream transliteration
character pool has sufficient coverage. Use `--top-k N` to change it.

## 4. Select Hanzi

```bash
python scripts/select_hanzi.py
```

The selector reranks Hanzi with phonetic, reference-pool, and corpus-frequency
weights of 0.75, 0.15, and 0.10. Its reference pool is derived from the English
IPA table reproduced from Xinhua's *Names of the World's Peoples*. This is only
a reference character pool: Xinhua does not define it as a Vietnamese-to-Hanzi
standard. Characters outside the pool are marked as fallbacks requiring human
review.

Outputs:

- `dataset/hanzi_candidates.jsonl`: top Hanzi candidates and component scores;
- `dataset/poem_hanzi.jsonl`: synthetic silver poem lines with Hanzi and Pinyin;
- `dataset/hanzi_report.json`: coverage, review counts, provenance, and corpus
  statistics.

Character frequency is measured from the local Chinese train/dev/test corpus.
The reference mapping and its retrieval metadata are stored in
`resources/xinhua_english_reference.json`.

## 5. Decode with poetic rhyme constraints

```bash
python scripts/decode_poem_hanzi.py
```

The decoder constructs rhyme links between adjacent lục/bát and song-thất
lục-bát lines. Each connected rhyme path is optimized with Viterbi dynamic
programming over the Hanzi candidate lattice. Unlinked syllables retain their
best local candidate.

Outputs:

- `dataset/poem_hanzi_decoded.jsonl`: decoded synthetic silver lines, including
  candidate ranks and flags for changes from greedy selection;
- `dataset/decoder_report.json`: rhyme distance before/after decoding, local
  score tradeoff, total objective, change counts, and review counts.

The default pairwise rhyme weight is 0.12 and can be changed with
`--rhyme-weight`.
